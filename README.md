# DOGBOT 기반 AI 농작물 생육 및 이상 상태 모니터링 시스템

DOGBOT으로 농작물 재배 공간을 이동하며 이미지를 수집하고, AI 비전 분석을 통해 농작물의 생육 및 이상 상태 정보를 관리자에게 제공하는 캡스톤 프로젝트이다.

저장소 이름은 `dogbot-ai-crop-monitoring`으로 정한다. DOGBOT은 이동 및 촬영을 위한 로봇 플랫폼이며, AI는 수집한 농작물 이미지의 분석에 사용한다.

## 1. 프로젝트 개요

기존 Smart Campus Agent 주제에서 농작물 모니터링 주제로 전환하였다. 현재는 선행기술 조사와 팀원별 조사 결과 비교를 통해 개발 범위를 정리하는 단계이다.

아래 내용은 초기 구상이며, 구현 완료를 의미하지 않는다. 대상 작물, 분석 모델, 판단 기준 및 세부 기능은 팀 회의를 통해 결정한다.

## 2. 시스템 구상

| 구분 | 현재 구상 |
| --- | --- |
| 이동 | DOGBOT이 농작물 재배 공간을 이동 |
| 이미지 수집 | 카메라로 농작물 이미지 수집 |
| 상태 분석 | AI 비전 모델로 생육 상태, 이상 상태, 부패 또는 관리 필요 여부 등 분석 검토 |
| 결과 관리 | 수집 이미지와 분석 결과 저장 |
| 결과 제공 | 관리자가 분석 결과를 확인할 수 있는 방식 검토 |

필요 시 로봇 위치정보와 분석 결과를 연결하는 방안을 검토한다. 이동·촬영 방식, 분석 범위, 저장 구조 및 관리자 화면은 아직 확정하지 않았다.

## 3. 현재 진행 상황

- 농업·농작물·이동로봇·AI 비전 관련 특허 조사
- 특허 원문에 근거한 알고리즘 및 처리 구조 정리
- 팀원별 조사 결과 수집 및 비교
- 개발 범위와 워크플로우를 정하기 위한 회의 준비

현재 저장소 정리는 주제 전환에 따른 문서 정비이며, 새 시스템의 기능 구현이나 로봇 동작 검증 완료를 뜻하지 않는다.

## 6. 특허 조사 기준

특허는 제목과 초록뿐 아니라 청구항 및 상세한 설명에서 확인되는 기술 구성을 조사한다.

- 입력 데이터 → 처리 모듈 → 판단 기준 → 출력 → 반복·재처리 순서로 정리한다.
- 청구항에 기재된 구성과 상세한 설명의 실시예를 구분한다.
- 원문에서 확인되지 않는 내용은 추정으로 채우지 않는다.
- 공개공보와 등록공보를 구분하고, 공개된 내용을 등록된 권리로 단정하지 않는다.
- 조사 결과를 팀 회의에서 비교한 뒤 개발 범위와 워크플로우를 결정한다.
